# SmartStaff - HR Management System

## Overview
SmartStaff is a comprehensive, custom-built Human Resources Management System designed to streamline company administration. 
It provides a centralized platform to handle department organization, monitor employee attendance, process leave requests, 
and calculate payroll efficiently. 

## Features
* **🏢 Department & Employee Tracking:** Easily create organizational departments and maintain detailed employee profiles.
* **🕒 Time & Attendance:** Track employee working hours with high accuracy.
* **🏖️ Leave Management:** Employees can submit time-off requests, and the system automatically tracks their paid leave balances.
* **📅 Dynamic Calendars:** Employees have access to personalized calendars. Administrators have full, flexible control to modify schedules, adjust shifts, and manage calendar events globally.
* **💰 Payroll Calculation:** Automated payroll processing based on logged hours, leaves, and employee compensation profiles.

## Tech Stack
* **Backend:** C#, .NET
* **Database:** SQL Server, Entity Framework Core
* **Architecture:** ASP.NET Core MVC / Web API
